2 Exercise 1: Aristotle in Computer Science?

  • Write a few sentences where Aristotle's four causes are visible.

  • Write a few paragraphs where Aristotle’s four causes are visible.

    Aristotle’s four causes are used to “address the aspects of a thing” and better define its function. They are namely: the material cause, the efficient cause, the formal cause and the final cause.

  • Putting a few examples into sentences:

To replicate a Picasso painting (final cause), an artist paints (efficient cause) with brushes and paints (material cause) based on a tutorial (formal cause). Windows users stayed up all night (efficient cause) to download Emacs (final cause) with their quick-and-dirty computers (material cause) based on obsolete instructions on Canvas (formal cause). To prepare for Intro to CS (final cause), our group worked tirelessly (efficient cause) using gorgeous computers (material cause) as per Professor Danvy’s instructions (formal cause).

  • A slightly longer example:

Everyone in my suite was hungry so in order to satisfy everyone’s hunger (FIN), Jenny and John bought (E) ingredients from Fairprice (M) so they could cook pasta (FORM). When they came back from Fairprice, Jenny fried (E) mushrooms (M) with the induction cooker (FORM) to use as condiments for pasta (FIN).

However, in order to cook the mushrooms (FIN), Jenny turned up the heat (E) on the induction cooker (M), which released a lot of hot steam (FORM). Unfortunately, the smoke alarm detected (E) the smoke (M) and rang loudly (FORM) to alert Infra (FIN). Infra wanted to investigate the source of the alarm (FIN) and visited the 5th floor (FORM). However, our suite pretended (E) to be liberal arts students who do not understand science (FORM) when Infra came so we wouldn’t get in trouble. (FIN) (FIN - Final Cause, E - Efficient Cause, FORM - Formal Cause, M - Material Cause)

3 Exercise 4: How would Aristotle define a Compiler?

Write down the four causes of a compiler, according to Aristotle’s four causes.

  • Understanding Aristotle’s four causes

The four causes as defined by Aristotle include: (i) The Material Cause: the object the actions are being performed on (ii) The Efficient Cause: the actions being performed on the object (iii) The Formal Cause: the method of attaining the end-product (iv) The Final Cause: the end-product or goal obtained

  • Defining a Compiler:

A compiler is a program that translates a program written in the source language into a program written in the target language through instructions written in an implementation language. Breaking the definition into the four causes (i) The Material Cause: a program written in the source language (ii) The Efficient Cause: a compiler translates (iii) The Formal Cause: through instructions written in an implementation language (iv) The Final Cause: a program written in the target language

  • Understanding it as a whole

Thus, the compiler is a program which takes in “a program written in the source language” (the material cause), performs the action of translation on it (the efficient cause) by following “instructions written in an implementation language” (the formal causes) and translates it into “a program written in the target language” (the final cause). Takeaways from Exercise: This exercise helped break down a compiler into four parts - the three language components and its primary function of translation, thereby making it easier to understand.
