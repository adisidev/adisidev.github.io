1 Exercise 2

Given a source program and its input, an interpreter executes source_program on input:

run interpreter (source_program, input) = output

Typically, we run source_program on several inputs, not just one. So it is a good idea to specialize interpreter with respect to a given source_program.

To be concrete, say that interpreter is an interpreter for Python written in OCaml, and that the S-m-n function specializes a program written in OCaml into another program written in OCaml.

Questions:

  • In which language is source_program written?.

Okay, since Prof Danvy likes connecting Philosophy to Computer Science, let’s reason our answer in a logical, philosophical way that would make Aristotle proud.

  • Premise 1: An interpreter executes source programs.
  • Premise 2: The language an interpreter executes should be the same as the language the source program is written in.
  • Premise 3: The interpreter executes Python.

Conclusion: Hence, the language the source_program is written in is Python.

  • Apply the S-1-1 function appropriately to specialize the interpreter with respect to source_program, and characterize its result.

We first instantiate the characteristic equations:

run p (x, y) = result
S-1-1 (p, x) = p_x
   run p_x y = result

with:

  • interpreter for p
  • source_program for x
  • input for y
  • output for result

The result reads:

run interpreter (source_program, input) = output
S-1-1 (interpreter, source_program) = interpreter_source_program
   run interpreter_source_program input = output

And then the questions are:

  • in which language is interpreter_source_program written?
  • what is interpreter_source_program, i.e., what does it do when it is executed?
  • what is the relation between source_program and interpreter_source_program?
  1. interpreter_source_program must be written in the same language as the interpreter, as interpreter_source_program is simply a specialised version of the source_program based on the interpreter. Hence, interpreter_source_program must be written in OCaml.
  2. When interpreter_source_program is executed, it evaluates the input and gives the output. This result would be the same as if we were to run the interpreter with the source_program and said input.
  3. To me, this mimics the structure of a compiled program, where instead of the interpreter having to interpret the source_program every time we want to run it, the source_program simply becomes an executable. Instead of running the interpreter for the source_progran every time, interpreter_source_program becomes a shortcut on which we can run any input.

2 Exercise 6:

As a continuation of Exercise 2, specialize the program specializer with respect to interpreter, and characterize the resulting specialized program specializer: what does it do?
(To be concrete, say that PE is a program written in OCaml.)

We first instantiate the characteristic equations:

run p (x, y) = result
S-1-1 (p, x) = p_x
   run p_x y = result

with:

  • PE for p
  • interpreter for x
  • source_program for y
  • interpreter_source_program for result

The result reads:

run PE (interpreter, source_program) = interpreter_source_program
run PE (PE, interpreter) = PE_interpreter
   run PE_interpreter source_program  = interpreter_source_program

Additionally,

run interpreter_source_program input = output

Over here, PE_interpreter acts as a particular compiler for the language the source_program is written in. interpreter_source_program is the same as interpreter_source_program, as in exercise 2. Hence, PE_interpreter can compile any “source_program” written in the same language as source_program’s language (Python).
